Los archivos se procesan en este navegador y no se suben a un servidor de esta aplicación. El visor no diagnostica: organiza posibles hallazgos para que los revises y confirmes.

Aviso: Este visor es educativo. Los datos cargados solo se muestran después de una revisión y confirmación manual. No mide compresión, no interpreta imágenes como un radiólogo y no sustituye una evaluación médica. No fuerces rangos extremos. Si aparece debilidad nueva o progresiva, dificultad para caminar, pérdida extensa de sensibilidad, desmayo, visión doble persistente o cambios nuevos en vejiga/intestino, busca atención médica.
